# 헌옷일번지 PC 관리자 설치·사용

## 처음 실행하기

1. `HeonotDesk-Setup-1.0.2.exe`를 다운로드해 실행합니다.
2. **설치**를 누릅니다. 바탕화면 바로가기를 만들 수 있습니다.
3. 바탕화면의 **헌옷일번지 관리자**를 엽니다.
4. **안드로이드 관리자 앱에서 사용하던 비밀번호**를 입력합니다.

Windows 10/11용 프로그램입니다. Windows의 .NET Framework 4.8을 사용합니다. 현재 Windows 사용자에게 설치하며, 별도 Cloudflare 비밀키나 계정 설정은 필요 없습니다. PC 인터넷 연결은 필요합니다.

## 자동 업데이트

1.0.1부터 프로그램을 켤 때와 실행 중 매시간 새 버전을 자동 확인합니다. 새 버전이 있으면 자동 다운로드하고 파일 크기와 SHA-256을 검증합니다. 화면 위에 **업데이트하고 다시 시작**이 나오면 작업을 저장하고 누르세요. 확인 후 프로그램이 종료되고, 설치 파일이 자동 교체된 뒤 다시 실행됩니다. 로그인 정보와 서버 데이터는 유지됩니다. 왼쪽 **업데이트 확인**으로 직접 확인할 수도 있습니다.

처음 설치한 1.0.0에는 이 기능이 없으므로, 기존 프로그램을 닫고 최신 설치 파일을 한 번 실행해야 합니다. 이후에는 새 설치 파일을 직접 찾을 필요가 없습니다. 업데이트가 내려받아지지 않거나 검증되지 않으면 설치하지 않고 기존 프로그램을 유지합니다.

바탕화면·시작 메뉴·작업 표시줄·설치 창 아이콘은 헌옷일번지 로고로 표시합니다.

## 메뉴별 사용법

- **오늘의 현황**: 오늘 방문자, 조회수, 전화 버튼 클릭, 온라인 신청과 월별 그래프를 확인합니다.
- **유입 분석**: 구글 광고, 네이버 광고, 검색, 블로그, 카페, SNS 등의 조회·전화 클릭을 비교합니다. ‘오늘’과 ‘선택한 달’을 바꿀 수 있습니다.
- **사이트 상태**: 홈페이지 HTTP 응답, 응답 시간, DB 연결, 온라인 신청과 앱 알림 설정을 확인합니다. 프로그램이 켜져 있고 현황·유입·사이트 상태 화면을 보는 동안 60초마다 갱신합니다. 실제 시험 신청이나 문자는 보내지 않습니다.
- **수거 신청서**: 이름·전화번호·주소·메모를 검색합니다. 상태로 필터하고, 열 제목을 눌러 정렬합니다. 신청서를 선택해 **상세 / 수정**을 누르면 신청 내용, 예약 시간, 신청서 메모, 상태와 단골·블랙리스트 표시를 관리할 수 있습니다. **직접 작성**으로 전화 신청도 입력할 수 있습니다. 삭제는 다시 확인한 뒤 실행합니다.
- **데이터 관리**: 신청서, 날짜별 메모, 하루 금액, 고객 표시, 이전 고객 메모, 일별 통계, 유입 통계를 200건씩 봅니다. 행을 두 번 누르면 내용 전체를 확인할 수 있습니다. **메모·금액 작성**에서 날짜를 정하고 **기존 기록 불러오기**를 누른 다음 수정·저장하세요.

## 통계를 읽는 방법

기존에 수집하던 조회·전화 클릭·온라인 신청 통계는 유지됩니다. 새 방문자·유입 경로 집계는 이번 배포 이후부터 기록됩니다. 과거 광고 유입은 복원할 수 없습니다.

- 방문자: 브라우저에 매일 바뀌는 임의 번호를 저장해 당일 중복 방문을 제외합니다. 사람 수와 정확히 같지 않습니다. 다른 기기·브라우저는 별도로 집계하며 저장·광고 차단 등으로 누락될 수 있습니다.
- 조회수: 새로고침과 재방문을 포함합니다.
- 전화 클릭: 홈페이지의 전화번호를 누른 횟수이며 실제 통화 연결 수가 아닙니다.
- 온라인 신청: 서버가 접수를 완료한 신청 건수입니다. 관리자가 직접 작성한 건은 포함하지 않습니다.
- 유입 경로: 광고 식별자, UTM 태그, 방문 출처를 기준으로 분류합니다. 광고 클릭 수나 광고비는 광고 관리자 수치와 다를 수 있습니다.

## 광고 유입을 구분하려면

구글 광고 자동 태그가 켜져 있거나 네이버 검색광고의 자동추적 URL을 사용하면 지원되는 식별자로 구분됩니다. URL 태그가 제거되면 광고 방문을 정확히 알 수 없습니다. 필요하면 **유입 분석 → 광고 링크 만들기**에서 링크를 복사해 광고 관리자에 도착 URL로 설정하세요.

- 구글 예시: `https://1beonji.com/?utm_source=google&utm_medium=cpc&utm_campaign=pickup`
- 네이버 예시: `https://1beonji.com/?utm_source=naver&utm_medium=cpc&utm_campaign=pickup`

광고 플랫폼별 경로를 구분하며, 개별 광고 소재·검색어·광고비를 가져오는 계정 연동은 포함하지 않습니다. 이 프로그램을 만들면서 실제 광고 계정의 설정을 바꾸지는 않았습니다.

## 내보내기와 백업

**선택 자료 CSV**는 선택한 표의 전체 자료를 엑셀에서 볼 수 있는 파일로 저장합니다. 신청서 화면의 **CSV 저장**은 불러온 신청서 전체를 저장합니다.

**전체 업무 자료 백업**은 업무 표 8개의 자료를 JSON으로 저장합니다. 비밀번호, 비밀키, 로그인 실패 IP, 앱 알림 토큰, 방문자 임의 식별자는 내보내지 않습니다. 백업에는 고객 개인정보가 있으니 본인만 접근할 수 있는 폴더에 보관하세요.

백업은 확인·보관용 자료입니다. Cloudflare DB 전체 이미지나 원클릭 복원 파일이 아닙니다. 표별로 순서대로 조회하므로 백업 도중 다른 기기에서 바꾼 내용과 시점 차이가 있을 수 있습니다. 대량 정리 전에는 파일을 보관해 두세요.

로그인 유지를 선택하면 비밀번호가 아닌 로그인 토큰을 현재 Windows 계정 전용 암호화 방식으로 저장합니다. **로그아웃**하면 이 정보도 지웁니다. 공용 PC에서는 로그인 유지를 해제하세요.

## 제거하기

Windows **설정 → 앱 → 설치된 앱 → 헌옷일번지 관리자 → 제거**, 또는 시작 메뉴의 **프로그램 제거**를 누릅니다. 서버의 신청서나 DB는 삭제되지 않습니다. 제거 프로그램 파일 자체만 설치 폴더에 남을 수 있습니다.

## 신청서별 유입 경로

1.0.2부터 수거 신청서 목록과 상세 정보에 유입 경로가 표시됩니다. 적용 후 홈페이지로 접수된 신청부터 구글 광고·네이버 광고·검색·블로그·카페 등을 구분합니다. 이전 신청과 추적 정보가 없는 신청은 확인 불가, 관리자 작성 신청은 관리자 직접 작성으로 표시합니다. 브라우저가 전달한 유형이며 실제 광고 기여를 보증하지 않습니다. 전체 URL·검색어·광고 클릭 식별자는 저장하지 않습니다.
