# 네이버 카페·블로그 글 문자 바꾸기

네이버 카페의 **글 수정 화면에서만** 제목과 본문의 특정 문자를 찾아 바꾸는 Chrome/Edge 확장 프로그램입니다.
최신 편집기와 구형 SmartEditor의 별도 본문 편집 영역을 모두 지원합니다.

`sajin1366` 블로그의 ‘운영자방문수거후기’에서 네이버 자체 검색 결과를 모든 페이지에 걸쳐 가져온 뒤, 실제 게시글이 존재하고 본문에 기존 번호가 남아 있는지 다시 검증합니다. 검증된 글만 사용자의 버튼 입력에 따라 하나씩 수정합니다.

## 설치 방법

1. 이 폴더를 원하는 위치에 보관합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다. Edge는 `edge://extensions`입니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 이 `naver-cafe-text-replacer` 폴더를 선택합니다.

## 사용 방법

1. 네이버 카페에서 바꿀 글의 **수정 화면**을 엽니다.
2. 브라우저 도구 모음에서 **네이버 카페 글 문자 바꾸기**를 엽니다.
3. `찾을 문자`와 `바꿀 문자`를 입력합니다.
4. 먼저 **미리보기**로 일치 개수를 확인합니다.
5. **바꾸기**를 누르고 글의 제목과 본문을 확인합니다.
6. 이상이 없으면 네이버 화면의 **등록** 버튼을 직접 누릅니다.

### 블로그 순차 수정

1. 네이버에 로그인한 Chrome에서 확장 프로그램을 엽니다.
2. **블로그 글 순차 수정 도구 열기**를 누릅니다.
3. 찾을 문자와 바꿀 문자를 입력하고 **번호가 있는 글만 찾기**를 누릅니다.
4. **다음 글 열고 문자 바꾸기**를 누릅니다.
5. 열린 작업 탭에서 변경 내용을 확인하고 네이버의 **발행** 버튼을 직접 누릅니다.
6. 순차 작업 도구로 돌아와 **다음 글 열고 문자 바꾸기**를 다시 누릅니다.
7. 실패한 글은 실패로 기록되며, 같은 버튼을 눌러 다음 글을 계속 처리할 수 있습니다.
8. 작업 후 결과 CSV를 저장합니다.

작업 도중에는 순차 작업 도구 탭을 닫지 마세요. 작업 탭을 닫으면 다음 실행 시 새 작업 탭을 자동으로 만듭니다.
SmartEditor ONE의 본문 로딩을 최대 30초 기다리며, 한 전화번호가 여러 서식 조각으로 나뉘어 있어도 연결해서 찾습니다.
실패할 경우 접근 가능한 프레임, 편집 후보, 화면 내 문자 포함 여부를 오류 메시지에 표시합니다.
SmartEditor의 클래스 이름과 관계없이 실제로 활성화된 편집 영역을 인식합니다.
대상 문자가 포함된 SmartEditor ONE 블록을 자동으로 찾아 선택하고, 화면 아래쪽 블록은 자동 스크롤해서 활성화합니다.
블록 안에서 대상 문자열의 실제 화면 좌표를 계산해 정확한 문단을 클릭합니다.
문자열 전체가 정확히 선택됐는지 다시 검사한 다음 Chrome의 실제 삭제·문자 입력 경로로 교체하므로 SmartEditor의 저장 데이터에도 반영합니다. 선택이 정확하지 않으면 글을 건드리지 않고 실패로 기록합니다.
이 기능 때문에 설치 또는 업데이트 시 **디버거 권한** 안내가 표시됩니다. 글 내용을 입력하는 동안에만 작업 탭에 연결하며 입력 직후 해제합니다.

잘못 바꿨다면 글을 등록하기 전에 확장 프로그램의 **방금 변경 되돌리기**를 누릅니다.

## 안전 범위

- 글을 자동 등록하거나 여러 게시글을 자동 순회하지 않습니다.
- 입력한 문자는 이 브라우저의 확장 프로그램 저장소에만 보관됩니다.
- 네이버 계정이나 비밀번호를 읽거나 저장하지 않습니다.
- 편집 가능한 제목·본문 요소만 검사하며, 일반 페이지 문구는 바꾸지 않습니다.

네이버 편집기 구조가 변경되면 일부 편집 화면에서 작동하지 않을 수 있습니다.
