# 잠금 화면 위젯 안내와 문자 문구

설정 → 업데이트 확인에서 **1.4.17**을 설치하세요.

## 잠금 화면에서 같은 신청 위젯 보기

One UI 8.5의 일반 잠금 화면 위젯 메뉴는 지원 앱을 제한합니다. **굿락 → LockStar(락스타)의 앱 위젯 기능**에서 기존 신청 목록 위젯을 선택하는 방식으로 사용합니다. 휴대폰에 위젯을 배치하는 작업은 사용자가 한 번 해야 합니다.

1. Galaxy Store에서 **굿락(Good Lock)**과 **LockStar**를 설치하거나 업데이트하세요.
2. 굿락 → LockStar → 잠금 화면 편집 → **앱 위젯**을 선택하세요. 잠금 화면을 길게 누른 뒤 편집 화면의 LockStar 메뉴로 들어갈 수도 있습니다. 메뉴 이름은 LockStar 버전에 따라 달라질 수 있습니다.
3. **헌옷일번지 신청 목록**을 선택하고 크기·위치를 정해 저장하세요.

잠금 화면을 지원하는 위젯 호스트에서도 기존 목록과 같은 이름, 희망 날짜, 전체 주소, 상태, 대면/비대면 아이콘을 제공합니다. 위젯 투명도와 자동 갱신 기능도 같은 제공자를 사용합니다. 신청 상세 화면이나 설정을 열 때는 잠금을 해제해야 합니다.

앱 설정 → **잠금 화면 위젯**에도 단계별 안내와 굿락 설치 페이지 버튼을 넣었습니다. 실제 S26에 대한 배치는 직접 확인해야 하며, LockStar에 앱 위젯 메뉴가 없거나 위젯이 표시되지 않으면 해당 화면을 확인해 다음 조치를 정해야 합니다. 앱 업데이트가 삼성 잠금 화면에 위젯을 자동 배치하지는 않습니다.

## 문자 보내기

신청서 상세 화면의 말풍선 아이콘을 누르면 해당 번호로 메시지 앱을 열고 아래 문구를 입력합니다. 날짜·요일·대면/비대면은 신청 내용에 맞게 바뀝니다. 전송은 메시지 앱에서 직접 누릅니다.
