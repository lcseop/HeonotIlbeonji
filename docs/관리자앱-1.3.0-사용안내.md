# 관리자 앱 1.3.0

새 APK를 휴대폰으로 옮겨 열고 **업데이트**를 누르세요. 기존 앱을 삭제할 필요는 없습니다.

## 예약 시간과 신청서 메모

1. 신청서를 열고 **상세 보기**를 누르세요.
2. 아래쪽 **관리자 기록 → 예약 시간 · 메모 수정**을 누르세요. 하단의 메모 아이콘으로도 열 수 있습니다.
3. **시간 선택**에서 시와 분을 고르고, 필요하면 신청서 메모를 적으세요.
4. **저장**을 누르세요. 홈페이지에서 고객이 작성한 희망 날짜, 시간대, 문의 내용은 유지됩니다.

예약 시간을 없애려면 **해제 → 저장**을 누르세요. 메모만 지우려면 메모 내용을 비운 후 저장하세요.

## 달력과 메모 목록

- 달력에서 날짜를 누르면 해당 날짜의 신청서를 볼 수 있습니다.
- 달력 목록에는 예약 시간이 보입니다. 등록하지 않았다면 희망 시간대와 **예약 시간 등록 안됨**이 보입니다.
- **메모** 탭에는 신청서에 남긴 메모를 모아서 보여줍니다. 이름, 전화번호, 메모 내용으로 검색하거나 정렬할 수 있습니다.
- 메모를 누르면 해당 신청서가 열립니다. 같은 전화번호로 신청이 여러 번 들어와도 신청서마다 별도 기록입니다.
- 이전 버전에서 남긴 고객 메모는 **이전 메모**에 보관했습니다. 특정 신청서에 임의로 연결하거나 삭제하지 않았습니다.

## 화면 조작

- 목록을 아래로 스크롤하면 상단 탭과 작성·정렬 버튼이 접힙니다. 위로 스크롤하면 다시 나타납니다.
- 달력 아래 달력 모양 아이콘을 누르면 오늘로 이동합니다.
- 상세 화면 맨 아래에는 전화, 연락처 추가, 메모, 연락 완료, 처리 완료, 삭제 아이콘이 한 줄로 있습니다.
- 아이콘을 길게 누르면 설명이 표시됩니다. 삭제는 확인 창에서 다시 확인해야 합니다.

신청서를 삭제하면 그 신청서의 예약 시간과 메모도 함께 삭제됩니다.
