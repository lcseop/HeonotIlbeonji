# 수거 신청 사이드 패널

설정 → 업데이트 확인에서 **1.4.15**를 설치하세요.

1. 앱에 로그인하고 톱니바퀴 → **사이드 패널 → 패널 켜기**를 누릅니다.
2. 휴대폰 설정에서 **헌옷일번지 → 다른 앱 위에 표시**를 허용하고 앱으로 돌아옵니다. 일부 기기는 앱 목록에서 헌옷일번지를 찾아야 합니다.
3. 화면 오른쪽 손잡이를 왼쪽으로 끌거나 누르면 신청 목록이 열립니다. 손잡이를 위아래로 끌면 위치가 저장됩니다.

새 신청과 연락 완료 신청을 희망 날짜순으로 함께 표시합니다. 이름·날짜·전체 주소·대면/비대면 아이콘을 볼 수 있으며, 신청을 누르면 앱의 상세 화면으로 이동합니다. 목록은 위아래로 스크롤됩니다. 패널 바깥이나 닫기 아이콘을 누르면 닫힙니다.

패널이 실행되는 동안 5분 간격으로 갱신을 시도하며, 열 때와 새 신청 알림·앱 수정 시에도 갱신합니다. 화면이 꺼지거나 휴대폰이 절전 상태이면 갱신이 늦어질 수 있습니다. 잠금 화면에서는 신청 내용을 표시하지 않습니다.

끄려면 앱 설정 → 사이드 패널 → **패널 끄기**, 또는 사이드 패널 알림의 **패널 끄기**를 누르세요. 패널 사용 중에는 안드로이드가 실행 알림을 표시합니다. 재부팅하거나 휴대폰이 앱을 종료한 뒤 손잡이가 사라지면 앱을 한 번 열어 주세요. 로그아웃하면 손잡이와 신청 목록이 사라집니다.

삼성 기본 엣지 패널과 별도로 동작하는 기능입니다. 기본 엣지 손잡이와 겹치면 손잡이를 위아래로 옮겨 사용하세요.
