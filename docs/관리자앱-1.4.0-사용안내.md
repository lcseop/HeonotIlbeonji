# 하루 금액과 월 합계

앱의 **톱니바퀴 → 업데이트 확인**에서 1.4.0을 설치하세요.

1. 아래 **달력**을 누릅니다.
2. 기록할 날짜를 누르고 **금액 · 메모 수정**을 누릅니다.
3. 그날 준 금액과 받은 금액을 **원 단위 숫자**로 입력합니다. 비워두면 0원입니다.
4. 필요한 하루 메모도 적고 **하루 기록 저장**을 누릅니다.

날짜를 누르면 해당 날짜의 기록 위치로 이동합니다. 아래 **달력** 탭을 다시 누르면 달력 위쪽으로 돌아갑니다.

달력 아래에 선택한 달의 **준 금액 합계, 받은 금액 합계, 차액**이 나옵니다. 이전 달·다음 달 화살표로 다른 달도 확인할 수 있습니다. 신청서 필터를 바꿔도 금액 합계는 달 전체를 기준으로 합니다.

차액은 **받은 금액 − 준 금액**입니다. 입력하지 않은 다른 비용은 포함하지 않습니다. 매번 저장하면 그 날짜의 금액을 수정하는 것이며, 기존 금액에 추가로 더하지 않습니다.

금액과 하루 메모는 관리자 서버에 함께 저장됩니다. 기존 날짜 메모는 그대로 이어서 사용합니다. 인터넷 연결 문제로 저장하지 못하면 입력 화면이 유지됩니다.

## 더 간단해진 이동

- **신청서 / 달력 / 메모**는 아래에 항상 보여서 한 번 누르면 이동합니다.
- 위에는 해당 화면의 **작성·정렬·필터** 기능만 둡니다.
- **메뉴 접기 / 펼치기**는 계속 사용할 수 있습니다. 메뉴를 접어도 아래 탭은 보입니다.
- 새로고침은 위쪽의 둥근 화살표 아이콘입니다.
