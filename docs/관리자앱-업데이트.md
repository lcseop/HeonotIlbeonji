# 앱 안에서 업데이트하기

**1.4.0 추가:** 달력에서 하루별 준 금액·받은 금액·메모를 함께 저장하고 월 합계와 차액을 확인할 수 있습니다. 신청서·달력·메모 이동 버튼을 하단에 고정했습니다. 자세한 순서는 `관리자앱-1.4.0-사용안내.md`를 보세요.

**1.3.4 수정:** 스와이프로 메뉴를 숨기고 표시하는 기능을 제거했습니다. 상단의 **메뉴 접기 / 메뉴 펼치기** 버튼으로 직접 조절합니다. 버튼은 메뉴를 접어도 계속 보입니다.

**1.3.3 수정:** 요약 보기·접기에서 해당 신청서만 변경합니다. 전체 목록과 달력을 다시 생성하며 전환하던 효과를 제거해 태블릿의 화면 깜빡임을 방지합니다.

**1.3.2 수정:** 신청서·메모 목록이 짧아 스크롤할 수 없는 상태에서도, 목록을 손가락으로 아래로 쓸어내리면 숨겨진 상단 메뉴가 다시 나타납니다.

자동 업데이트 기능이 없는 이전 버전에서는 **1.3.1 APK를 한 번 직접 설치**해야 합니다. 기존 앱 위에 업데이트 설치하세요.

그다음부터는 앱을 열면 새 버전을 확인합니다. 새 버전 안내에서 **업데이트**를 누르면 다운로드 후 휴대폰의 설치 화면이 열립니다. **설치**를 눌러 마무리하세요.

첫 업데이트 때 설치 허용 안내가 나올 수 있습니다. **설정 열기 → 이 출처 허용 켜기 → 뒤로 가기**를 하면 설치 화면으로 이어집니다.

앱의 **톱니바퀴 → 업데이트 확인**에서 언제든 확인할 수도 있습니다. 자동 확인은 6시간 간격이고, 확인 실패 시 신청서 사용에는 영향을 주지 않습니다.

다운로드 오류나 설치 취소 후에는 **업데이트 확인**을 다시 누르세요. 검증을 통과한 파일이 남아 있다면 다시 다운로드하지 않고 설치를 진행합니다.

## 다음 버전을 배포할 때

1. `android-admin/app/build.gradle`의 `versionCode`를 올리고 `versionName`을 정합니다.
2. `https://1beonji.com` 서버 주소로 APK를 빌드하고 테스트합니다. **기존 앱과 같은 서명 키**를 사용합니다.
3. APK 파일을 `outputs/android/헌옷일번지-관리자-버전.apk`에 저장합니다.
4. `node scripts/publish-admin-update.mjs`를 실행합니다. 필요하면 APK 경로와 변경 안내를 인자로 넘깁니다.
5. 생성된 `public/admin-app`의 APK와 `latest.json`을 코드 변경과 함께 기존 사이트에 배포합니다.
6. 공개된 파일의 크기·SHA-256과 `/api/admin/native-update`의 버전을 확인합니다.

앱은 다운로드 파일의 크기·해시, 앱 이름, 버전 번호, 서명을 확인합니다. 다른 앱이나 서명이 다른 APK는 설치 화면으로 넘기지 않습니다. 버전별 APK 주소를 유지하며 새 버전의 파일은 기존 주소에 덮어쓰지 않습니다.

다운로드 정보에는 앱 버전과 파일 정보만 들어갑니다. 신청서·메모는 기존처럼 관리자 로그인 후에만 확인할 수 있습니다.
