# 달력과 통계

앱의 **톱니바퀴 → 업데이트 확인**에서 1.4.1을 설치하세요.

- **달력:** 날짜를 선택하면 **신청서 목록 → 하루 금액·메모** 순서로 표시됩니다. 월 합계는 달력에서 제외했습니다.
- **통계:** 아래 **통계** 탭에서 월별 준 금액·받은 금액·차액을 확인합니다. 위의 이전 달·다음 달 화살표로 조회할 달을 바꿉니다.
- 금액 제목은 글자를 크게 설정해도 **준 금액**, **받은 금액**이 한 줄로 보이도록 바꿨습니다.

저장한 금액과 메모는 그대로 유지됩니다. 금액 입력은 달력의 **금액 · 메모 수정**에서 합니다.
