# 화면에서 바로 정렬·필터 조절하기

**톱니바퀴 → 업데이트 확인**에서 1.4.2를 설치하세요.

- **정렬:** 현재 정렬 방식이 보이는 선택 상자를 눌러 바로 바꿉니다. 메모 목록도 같은 방식입니다.
- **필터:** 새 신청·연락 완료·처리 완료 체크 버튼을 눌러 표시할 상태를 여러 개 선택합니다. 선택 즉시 목록과 달력의 건수가 바뀝니다. 모두 체크를 해제하면 신청서는 표시되지 않습니다.
- **미완료 날짜순:** 새 신청과 연락 완료만 자동으로 체크하고, 희망 날짜가 빠른 순으로 표시합니다. 날짜 미정 신청서는 마지막에 나옵니다.

미완료 날짜순을 선택한 후 상태 체크를 직접 바꾸면 정렬 표시는 일반 **희망 날짜순**으로 바뀝니다. 체크한 상태는 그대로 적용됩니다.

월별 금액 통계는 신청서 필터와 관계없이 달 전체를 기준으로 계산합니다.
