# 수거 지역 지도 수정

홈페이지의 수거 지역은 카카오 지도에 색 도형으로 표시됩니다. 현재 일산·고양·김포·파주·운정·서울 강서구를 표시합니다. 경계는 **상담용 예시**이며 공식 행정구역 경계나 방문 확약이 아닙니다. 방문 가능 여부는 주소와 수거 품목을 확인한 뒤 안내합니다.

## 카카오맵 연결

1. [카카오 디벨로퍼스](https://developers.kakao.com)에 앱을 만들고 **JavaScript 키**를 발급합니다. REST API 키나 Admin 키를 사용하지 않습니다.
2. JavaScript 키 설정에서 실제 홈페이지 도메인을 JavaScript SDK 도메인에 등록합니다. 로컬에서 확인하려면 로컬 주소도 추가합니다.
3. 로컬 개발은 비공개 `.env.local` 파일의 `KAKAO_MAP_JAVASCRIPT_KEY=` 뒤에 입력합니다. 호스팅할 때는 같은 이름의 환경변수로 등록하고 서버를 재시작하거나 다시 게시합니다. JavaScript 키는 지도 실행을 위해 브라우저에 전달되는 공개 키입니다. SOLAPI API Secret과 혼동하지 마세요.

키가 아직 없거나 지도를 불러오지 못하면 홈페이지에 **도형 미리보기**가 표시됩니다. 카카오맵이 연결되면 동일한 도형을 실제 지도 위에 표시합니다.

## 범위 편집

`/html/area-editor.html`을 열면 지역 이름과 색을 변경하고 경계 점을 움직이거나 추가·삭제할 수 있습니다. 카카오맵 키를 넣은 뒤에는 실제 지도에서 편집합니다. 키가 없으면 미리보기 도형에서도 편집할 수 있습니다.

「이 브라우저에 임시 저장」은 본인의 브라우저에만 저장됩니다. 방문자 전체에 반영하려면 「설정 파일 다운로드」로 받은 `service-areas.json`을 프로젝트의 `public/data/service-areas.json`과 교체한 뒤 사이트를 다시 게시해야 합니다. 편집 화면에는 서버 저장 권한이 없으므로 공개 사이트에서 임의로 방문 범위를 바꿀 수 없습니다.

좌표는 `[위도, 경도]` 순서입니다. 필요하면 [service-areas.json](../public/data/service-areas.json) 파일에서도 직접 수정할 수 있습니다. 지역 목록과 도형은 이 파일 하나에서 관리합니다.
