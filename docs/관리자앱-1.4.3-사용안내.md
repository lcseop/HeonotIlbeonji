# 저장 대기 시간 개선

톱니바퀴 → 업데이트 확인에서 **1.4.3**을 설치하세요.

- 목록 다운로드 때문에 신청서 저장이 뒤에서 기다리지 않도록 저장 작업을 분리했습니다.
- 신청서, 예약 메모, 상태 변경, 삭제, 하루 기록은 서버가 저장을 확인한 뒤 화면에 바로 반영합니다. 전체 목록을 다시 내려받는 시간을 줄였습니다.
- 목록을 불러오거나 저장할 때 회전하는 로딩 표시가 나옵니다.
- 저장 중에는 중복 저장을 막고, 실패하면 입력 내용을 유지해 다시 저장할 수 있습니다.

실제 저장 시간은 통신 상태에 따라 달라집니다. 저장 완료 표시는 서버 확인 후에만 표시합니다.
