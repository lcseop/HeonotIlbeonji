# 홈 화면 신청 목록 위젯

앱 설정 → 업데이트 확인에서 **1.4.9**를 설치하고 로그인해 주세요.

1. 휴대폰 홈 화면의 빈 곳을 길게 누릅니다.
2. **위젯 → 헌옷일번지 → 헌옷일번지 신청 목록**을 선택해 홈 화면에 놓습니다.
3. 위젯 테두리를 조절하면 가로·세로 크기를 바꿀 수 있습니다. 목록은 위아래로 스크롤됩니다.

- **새 신청 / 연락 완료**만 희망 날짜가 빠른 순으로 함께 표시합니다. 처리 완료는 제외합니다. 같은 날짜면 새 신청을 먼저 보여줍니다.
- 지난 희망 날짜의 미처리 신청도 앞쪽에 표시하며, 날짜가 없는 신청은 마지막에 표시합니다.
- 이름, 희망 날짜(두 자리 연도), 상태가 보입니다. 신청을 누르면 앱의 해당 상세 화면이 열립니다.
- 오른쪽 위 새로고침 버튼으로 최근 신청을 불러옵니다. 앱에서 신청을 변경하거나 새 신청 알림을 받으면 위젯 갱신을 요청합니다. 정기 갱신은 약 30분 간격이며 휴대폰 절전·네트워크 상태에 따라 늦어질 수 있습니다.
- 로그인 전에는 신청 내용을 표시하지 않습니다. 로그아웃하면 위젯 목록도 지워집니다.
- 신청이 100건을 넘으면 날짜가 가까운 100건을 표시합니다. 위젯 제목을 누르면 앱에서 전체 목록을 확인할 수 있습니다.
