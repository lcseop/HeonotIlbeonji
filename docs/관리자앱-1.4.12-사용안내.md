# 위젯 투명도와 자동 갱신

앱 설정 → 업데이트 확인에서 **1.4.12**를 설치하세요.

**투명도 조절**

위젯 오른쪽 아래 톱니바퀴를 누릅니다. 배경 투명도를 0~100%로 조절하고 **저장**을 누르세요. 0%는 배경이 보이며, 100%는 배경이 완전히 투명합니다. 글자와 아이콘은 투명해지지 않습니다. 여러 위젯을 두면 각각 다르게 설정할 수 있습니다.

**자동 갱신**

로그인되어 있고 홈 화면에 위젯이 있으면 새로고침을 누르지 않아도 자동으로 갱신합니다. 5분 간격의 자동 확인을 요청하지만 안드로이드의 절전·백그라운드 실행·네트워크 제한 때문에 실제 갱신 시점은 늦어질 수 있습니다. 화면이 꺼져 있을 때 갱신을 위해 휴대폰을 강제로 깨우지 않습니다.

정기 백그라운드 작업도 함께 등록되어 재부팅 후 자동 갱신을 복원합니다. 새 신청 알림을 받거나 앱에서 신청 내용을 수정하면 갱신을 요청합니다. 오른쪽 위 새로고침 버튼은 그대로 사용할 수 있습니다. 로그아웃하거나 모든 위젯을 삭제하면 자동 갱신 작업을 중지합니다.
