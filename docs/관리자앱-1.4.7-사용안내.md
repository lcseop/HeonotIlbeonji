# 홈페이지 통계

앱의 톱니바퀴 → 업데이트 확인에서 **1.4.7**을 설치하세요.

하단 **통계 → 홈페이지**에서 선택한 달의 합계와 날짜별 기록을 볼 수 있습니다. 월 양쪽 화살표로 이전·다음 달을 선택하고, 오른쪽 위 새로고침으로 최근 수치를 불러옵니다. **금액**을 누르면 기존 월 금액 통계가 나옵니다.

- **홈페이지 조회:** 홈페이지가 열린 횟수입니다. 같은 사람의 재방문과 새로고침도 포함합니다.
- **전화 버튼 클릭:** 홈페이지의 전화번호 또는 전화 상담 버튼을 누른 횟수입니다. 실제 통화 연결 여부는 확인하지 않습니다. 빠른 연속 터치는 한 번으로 처리합니다.
- **온라인 신청 완료:** 홈페이지 신청서를 서버가 정상 접수한 건수입니다. 앱에서 직접 작성한 신청은 제외합니다. 접수된 신청서를 나중에 삭제해도 과거 통계는 유지합니다.

한국 시간 기준으로 집계하며 구글·네이버 광고, 일반 검색, 직접 접속을 모두 합친 수치입니다. 광고 성과로 인정된 전환만 표시하는 Google Ads 보고서와는 숫자가 다를 수 있습니다. 집계 시작 전 기록은 복원하지 않습니다.

통계에는 날짜별 숫자만 저장하며 고객의 이름·전화번호·주소, 방문자 IP 또는 방문자 식별 쿠키를 저장하지 않습니다. 중복 전송을 막는 임의의 이벤트 번호는 집계 숫자와 별도로 저장하고 오래된 번호는 정리합니다. 브라우저가 통계 전송을 차단하거나 연결이 끊기면 조회·전화 클릭 일부가 집계되지 않을 수 있습니다.
